# スマホ撮影するだけ！感熱紙レシート退色防止ファイリングシミュレーター

数ヶ月で文字が消えてしまう感熱紙レシートをスマホで撮影し、劣化を防ぐ保存方法とデジタル管理の最適な組み合わせを提案するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/receipt-ink-archiver/）。
2. 画面の指示に従って操作します。
